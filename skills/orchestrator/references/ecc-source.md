This is a local adaptation, not an upstream installation or claim of ECC runtime
compatibility. Useful methods are rewritten for existing project ownership,
Windows/PowerShell, available tools, scoped authorization and honest evidence.
Runtime installers and automatic memory mutation are not part of this entrypoint;
hooks, MCP configurations, and services remain conditional capabilities whose
availability, authorization, and side effects must be verified before use.

Reviewed source concepts: search-first, iterative-retrieval, verification-loop,
eval-harness, ai-regression-testing, mle-workflow, skill-stocktake,
strategic-compact, security-review, api-design, database-migrations,
content-hash-cache-pattern and cost-aware-llm-pipeline. Only the concepts named in
this skill's entrypoint/references are adapted here. Generic thresholds, tool names,
framework snippets and model identifiers are not authoritative local defaults.

Private adaptation and rollback records are not distributed.
