# Agent Toolkit

Purpose: share a portable, sanitized skills and preferences bundle; synchronize
approved local changes to GitHub; restore it on new coding-agent machines.

Ownership: local standalone skills and durable working preferences remain the
publisher's sources. This repository owns export policy, installers, public
templates, provenance and the generated distribution. New machines consume the
repo; only a configured publisher exports upstream. GitHub is distribution,
not a backup of credentials, private vault data or conversation memory.

Acceptance: reviewed public content; deterministic source export; digest and
privacy checks; installation into temporary Codex/Claude homes; preserved local
instructions; drift refusal; idempotence; safe uninstall; non-forced publishing;
registered recurring synchronization with observable errors.

The current project is not tracked in Linear. Do not create tracker records as
a side effect of sync. Local publisher paths belong only in ignored .local/.
