# Vault layout conventions

Vault root: `{{VAULT}}`. Configure it with the installer's `--vault` option.
Inspect the live vault; do not create this example structure unless requested.

Use Home.md for the top-level map and area Index.md files for navigation.
Keep durable project conventions in Project Management/ and project content in
Projects/ when the vault already follows that split. Link the two layers.
Use the live tracker for volatile status and runtime artifacts for behavior.

Preserve existing organization, aliases and historical context. Keep archives
separate from current notes. When moving or renaming a note, check all inbound
links and update affected indexes. Disambiguate repeated basenames with paths.
Escape wikilink aliases inside Markdown tables. Verify every changed local link.

See [index-snapshot.md](index-snapshot.md) for the public bundle's navigation
boundary. No private vault contents are included.
